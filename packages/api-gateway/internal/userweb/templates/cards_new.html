绑卡流程（PAN 单跳化）：
1. 浏览器 fetch POST 到 {{.CardCenterURL}}/v1/cards（HTTPS，cookie 带 jwt）
2. card-center 调 user-merchant-core IntrospectToken 验登录态 → 取 user_id

4. 浏览器再 POST /cards/attach 到 api-gateway，**只**带 stored_token + masked
5. api-gateway 把这条记录交给 user-merchant-core 持久化（不见 PAN）
